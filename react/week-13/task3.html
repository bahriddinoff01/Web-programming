Skills checklist with counter

Task: Study guide, exercise 3: show 6 programming skills as checkboxes with a live counter of the selected ones. If more than 3 are selected, show “Please select at most 3 skills.”

Live result

Loading…

How it works

  • The selected skills are an array in state. A checkbox uses checked, not value.
  • Checking adds the skill with [...prev, skill], and unchecking removes it with .filter().
  • checked={selected.includes(skill)} makes each box show the state.
  • The counter and the warning are worked out from selected.length on every render.
