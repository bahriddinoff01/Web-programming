Contact form with validation

Task: Study guide, exercise 2: a contact form with Name, Email and Message. Validate all three on submit, show the errors next to each field, then show a “Thank you” message and reset the form.

Live result

Loading…

How it works

  • One state object holds every field. One handleChange updates the right field with [name]: value, using the input's name attribute.
  • e.preventDefault() in onSubmit stops the browser from reloading the page.
  • validate() returns an object of error messages; if it has any keys, they are shown and nothing is sent.
  • Typing in a field clears its error, and after a valid submit the form is reset to EMPTY and the thank-you message shows the name.
