How it works

  • Three pieces of state: the user, a loading flag and an error message.
  • The effect depends on [userId]: it runs once when the page opens and again whenever another user is picked.
  • An effect function can't be async, so the async code lives in an inner function that the effect calls.
  • An AbortController lets the cleanup cancel a request that is no longer needed, so a slow old answer can't replace a newer one.
