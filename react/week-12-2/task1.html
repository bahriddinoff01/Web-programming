Page title sync

Task: Update document.title as the user types, and put the original title back with a cleanup function.

Live result

Loading…

How it works

  • Changing document.title is a side effect: it touches something outside React, so it goes in useEffect.
  • The dependency array [text] makes the effect run again only when the text changes.
  • The effect remembers the title it found, and its cleanup puts it back. React runs the cleanup before the next effect and when the component is removed.
