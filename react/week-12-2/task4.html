Week 12-2 · Task 4

GitHub user lookup

Task: Code challenge: an input and a Search button that fetch api.github.com/users/{username} and show the avatar, name, bio, followers and public repos, with a loading state and a 404 message. Bonus: abort the previous request.

How it works

  • input follows every keystroke, but username only changes when Search is pressed, so the effect (which depends on [username]) fetches once per search.
  • githubApi.js turns each kind of failure into a message: user not found (404), rate limit (GitHub allows 60 requests an hour without a key) and no connection.
  • Bonus: the cleanup calls controller.abort(), so if a new search starts before the old one finishes, the old request is cancelled.
  • GitHubUserCard is a separate component that only shows the data, and it is reused in Task 5.
