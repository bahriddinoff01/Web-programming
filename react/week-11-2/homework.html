Task: A ProjectCard (title, description, tech stack, GitHub link, demo link), a ProjectList that renders at least six cards from an array, and a FilterBar that filters them by technology with useState.

How it works

  • projects.js holds my real public projects; ProjectList turns the array into cards with .map() and spreads each object into props with {...project}.
  • ProjectCard only shows what it receives. The tech stack is a small list rendered with .map(), and the links open in a new tab.
  • The filter buttons come from the data: new Set(projects.flatMap(p => p.tech)) collects every technology once.
  • ProjectList owns the filter state and passes it down with onChange={setFilter}; FilterBar just calls it (lifting state up).
  • The visible cards are calculated with .filter() on every render, never stored in state.
