Rendering a list with keys

Task: Render an array of students with .map(), giving every item a unique, stable key.

Live result

Loading…

How it works

  • STUDENTS is a plain array of objects, kept outside the component because it never changes.
  • STUDENTS.map(...) turns each object into an <li>, and React shows the whole array.
  • Each <li> gets key={student.id}. The key lets React tell items apart when the list changes; the array index is avoided because it changes when items move.
