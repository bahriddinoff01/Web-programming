Add & remove tasks

Task: A text input and an Add button. Typed items are added to a list stored in state, and each item has a button that removes it.

Live result

Loading…

How it works

  • Two pieces of state: value holds the text in the input, and tasks holds the list.
  • The input is controlled: value={value} and onChange saves every keystroke with setValue.
  • addTasks ignores empty input (.trim()), adds a new { id, text } object with the spread [...prev, …], then clears the input.
  • .map() shows each task with key={task.id}; remove uses .filter() to keep every task except the clicked one.
