How it works

  • Banner returns null when there is no message, so nothing at all is rendered.
  • {loggedIn && unread > 0 && <span>…</span>}: the badge only appears when both conditions are true.
  • {loggedIn ? "Welcome back…" : "Please log in."} picks one of two texts; the button label works the same way.
  • useState is only used so both cases can be tried with the buttons.
