How it works

  • Greeting is a normal function whose name starts with a capital letter, so React treats <Greeting /> as a component, not an HTML tag.
  • It returns JSX: HTML-like markup that React turns into elements on the page.
  • GreetingApp uses it three times. Each <Greeting /> calls the same function and gets its own copy of the result.
