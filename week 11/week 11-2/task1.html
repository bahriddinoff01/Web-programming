Task: A button that shows and hides a paragraph of text, using a boolean state value.

How it works

  • useState(false) creates the state toggle, which starts as false (hidden).
  • Clicking the button calls toggleHandle, which flips toggle between true and false.
  • A ternary picks the button text: toggle ? "remove" : "show more".
  • {toggle && <p>…</p>} only creates the paragraph while toggle is true; when it is false, React removes it.
