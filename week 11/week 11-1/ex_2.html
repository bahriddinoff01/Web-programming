Render a list of notifications

Task: given an array of notifications [{ id, type, message }], render each one as a styled item. Show a checkmark for success, a warning icon for warning, and a default icon otherwise.

Live result

Loading React…

How it works

  • notifications.map() turns each object into a <NotificationItem />.
  • Each item gets key={n.id}, a stable unique id, not the array index.
  • A ternary picks the icon and colour: ✅ success, ⚠️ warning, ℹ️ anything else.
  • The icon is hidden from screen readers, and a text label ("Success:", "Warning:", "Info:") is read instead.
