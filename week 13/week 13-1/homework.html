Week 13-1 · Homework

Student profile editor

Task: A full student profile form: name, student ID (10 digits), major (dropdown), year (1–4 radio), bio and photo (file + preview). All fields are validated (ID exactly 10 digits, bio under 200 characters), the bio has a live character counter, and submitting shows a “Profile Preview” card. Stretch: skills as tags (Enter to add, × to remove).

How it works

  • The text fields, dropdown and radios share one state object and one handleChange; the ID field only keeps digits.
  • The photo is a File, so it has its own state. useEffect turns it into a preview URL with URL.createObjectURL, and the cleanup frees it with revokeObjectURL.
  • validate() checks every rule on submit and puts a message under each wrong field; the bio counter updates as you type.
  • On a valid submit, a copy of the form is saved and ProfilePreview shows it as a card; without a photo it shows the initials.
  • Stretch: SkillTags adds a tag on Enter (with preventDefault() so the form isn't submitted) and removes it with ×; the parent owns the list.
