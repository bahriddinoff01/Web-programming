Weather dashboard

Task: Show the current temperature, wind speed and weather description from the Open-Meteo API. Search by city name or by coordinates, fetch with useEffect whenever the search changes, and show loading and error states. Bonus: a “Use my location” button.

How it works

  • WeatherDashboard keeps one query state (a city, or coordinates). The effect depends on [query], so every new search fetches again, and it starts with Seoul.
  • A city name is first turned into coordinates with the Open-Meteo geocoding API, then the forecast API returns the current weather; no API key is needed.
  • Errors each get a clear message: city not found, coordinates out of range (checked before fetching), too many requests, and no connection.
  • The cleanup aborts an unfinished request, so a slow old answer can't replace a newer search.
  • Bonus: “Use my location” asks the browser for its position with navigator.geolocation and handles a blocked permission.
  • SearchForm and CurrentWeather only receive props; the weather codes are turned into words and emoji in weatherApi.js.
