GitHub profile with debounce

Task: Video lecture challenge: fetch a GitHub profile as the user types, with a loading indicator and a 404 message. Bonus: debounce the fetch by 500 ms.

Live result

Loading…

How it works

  • Effect 1 (debounce) starts a 500 ms timer on every keystroke; its cleanup cancels the previous timer, so only the last one finishes and sets username.
  • Effect 2 fetches whenever username changes, and its cleanup aborts an unfinished request.
  • One result object holds the status (idle, loading, error or done) so only one message can show at a time.
  • Typing a long name quickly sends one request instead of one per letter.
