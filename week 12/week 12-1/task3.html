Week 12-1 · Task 3

Scoreboard: lifting state up

Task: A parent ScoreBoard with two PlayerScore children. Each player has + and − buttons, and the parent shows the total of both scores.

Live result

Loading…

How it works

  • Both scores live in the parent ScoreBoard, because it needs both to show the total.
  • The total is calculated each render (firstScore + secondScore), not stored as separate state.
  • One reusable PlayerScore component is used twice, getting name, score, onIncrement and onDecrement as props.
  • The buttons call the functions they were given, which update the parent's state: data flows down, events flow up.
