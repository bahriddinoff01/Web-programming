Monday practice: Git

The Git exercises from Monday's class, done in order in the webpro-w9 repository. Each screenshot is from my own terminal.

E1

Create a repository

webpro-w9

Goal: turn my project folder into a Git repository.

$ git init

Result: Git created a hidden .git folder, so the folder is now a repository that can track my files.

E2

Make the first commit

webpro-w9

Goal: stage my files and save them as the first commit.

$ git commit -m "first commit"

Result: the files were saved as commit 6820ae5 with the message "first commit".

E3

Create a new branch

webpro-w9

Goal: create a branch for style changes and switch to it in one step.

$ git checkout -b feature-style

Result: Git switched to the new feature-style branch on my computer, so I could work on styles without changing main.

E4

Push the repository to GitHub

webpro-w9

Goal: connect my local repository to GitHub and upload my commits.

$ git remote add origin https://github.com/bahriddinoff01/webpro-w9.git
$ git push -u origin main

Result: my commits are on GitHub. Open the repository.

Friday practice: GitHub Pages

The GitHub Pages exercises from Friday's class, done in the webpro-w9 repository.

E1

Turn on GitHub Pages

webpro-w9

Goal: publish the repository as a website.

# On GitHub, in the webpro-w9 repository:
Settings → Pages → Deploy from a branch → main → / (root) → Save

Result: the site is live at bahriddinoff01.github.io/webpro-w9.

E2

Look at the default 404 page

webpro-w9

Goal: see what a visitor gets when a page doesn't exist, and decide if it's a good experience.

Before I added my own page, a missing address showed GitHub's generic "404 – File not found" page.

Is it a good user experience? No. It doesn't look like my site, it doesn't explain what happened in a friendly way, and it gives the visitor no way back to my pages. A better 404 page should match the site's style and include a link back home.

E3

Create a custom 404 page

webpro-w9

Goal: add my own 404.html so GitHub Pages shows it for missing pages.

$ git add 404.html
$ git commit -m "created a 404"
$ git push

My 404.html sits in the top folder of the repository next to index.html. It shows a big "404", the heading "Page not found" and a short friendly message that JavaScript picks at random each time the page loads.

Result: added in commits 09519fe and 507d3ab. Try a missing page to see it.
