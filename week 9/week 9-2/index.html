Team Project Accessibility Audit

A Lighthouse accessibility review of our team project, AI Travel Planner. It shows the starting score, the three problems Lighthouse found, and the code changes that fix them.

87 BEFORE

Score Overview

The first Lighthouse run gave the site an accessibility score of 87/100, with three failing checks. After fixing all three, the score went up to 100/100.

100 AFTER
01

Initial Audit

BEFORE

87 / 100

The first Lighthouse run found three accessibility problems on the home page.

THREE ISSUES

Names, Contrast & Headings

An icon button had no name, one badge had text that was too light, and the headings skipped a level.

02

Problems Identified

NAMES AND LABELS

Button has no accessible name

The round menu button only shows an icon. It has no text, so a screen reader just says “button” and the user can’t tell what it does.

CONTRAST

Text colour is too light

The badge uses text-blue-600 on bg-blue-100. That is a contrast ratio of 4.29:1, and the minimum for normal text is 4.5:1.

NAVIGATION

Headings skip a level

The page goes straight from <h1> to <h3> for the cards. Screen reader users move around by headings, so a missing level makes the page structure confusing.

03

Changes Made

1. Give the icon button a name

Add an aria-label that says what the button does.

BEFORE
<button
  class="flex md:hidden h-10 w-10 ..."
>
  <!-- icon only -->
</button>
AFTER
<button
  class="flex md:hidden h-10 w-10 ..."
  aria-label="Open menu"
>
  <!-- icon only -->
</button>

2. Make the badge text darker

Changing blue-600 to blue-700 raises the contrast above 4.5:1. The badge looks almost the same.

BEFORE · 4.29 : 1
<span
  class="text-blue-600 bg-blue-100
         px-4 py-2 rounded-4xl
         capitalize font-bold"
>
AFTER · passes 4.5 : 1
<span
  class="text-blue-700 bg-blue-100
         px-4 py-2 rounded-4xl
         capitalize font-bold"
>

3. Put the headings in order

Change the card titles from <h3> to <h2>, so headings go 1 → 2 with no gap. The text-3xl class keeps them the same size.

BEFORE
<h1>...</h1>

<h3 class="text-3xl">
  Card title
</h3>
AFTER
<h1>...</h1>

<h2 class="text-3xl">
  Card title
</h2>
04

Why These Changes Matter

aria-label

Screen readers read the label out loud, so users know the button opens the menu.

Colour contrast

Darker text is easier to read for people with low vision, and on bright screens outdoors.

Heading order

A clean heading outline lets assistive technology users jump between sections easily.

05

Final Audit

PASSED

100 / 100

After adding the aria-label, darkening the badge text and fixing the heading order, Lighthouse found no more accessibility problems.

Accessibility Improved

Three small changes took the team project from 87 to a perfect Lighthouse accessibility score.
